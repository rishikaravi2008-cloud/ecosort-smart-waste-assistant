# ♻️ EcoSort – Smart Waste Identification and Reuse Assistant

## About the Project
EcoSort is a web-based application designed to
support smart waste identification, proper waste
segregation, and creative reuse suggestions.

## Features
- Waste identification
- Waste segregation guidance
- Reuse suggestions
- User-friendly web interface

## Technologies Used
- Python
- HTML
- CSS
- JavaScript

## Project Structure
- app.py
- static/
- templates/

## Purpose
To encourage responsible waste management
and promote environmental sustainability.
## Installation and Setup

1. Clone the repository:

   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder:

   cd ecosort-smart-waste-assistant

3. Install dependencies:

   pip install flask

4. Run the application:

   python app.py

5. Open your browser and visit:

   http://127.0.0.1:5000
